# Contributing

Contributions are welcome.

```bash
git clone https://github.com/bafnayeygian/ReleaseNoteForge.git
cd ReleaseNoteForge
python -m pip install .
python -m unittest discover -s tests -v
```

Good contribution areas include GitLab/Bitbucket links, PR number extraction, semantic-version suggestions, custom categories, changelog update mode, HTML output, and contributor aliases.
